# 抽屉 / 弹窗复用列表数据审计（2026-11-25）

## 判定口径

- **复用**：列表行对象（`Row` / `Dict`）作为 prop 传入抽屉或弹窗，并用于**表单回填 / 功能入参**。
- **已隔离**：只传 `id` / `code` 等标识，组件打开时按标识拉详情；或详情由调用方先拉好再传入。
- 只拿列表行的名字当标题、只把 id 交给回调拉日志，单列为「仅展示 / 仅标识」，不算表单回填。
- 本次为静态代码审计，**未改代码、未跑门禁**。

## 结论

| 类别 | 数量 | 处置建议 |
|---|---:|---|
| 整行回填的编辑抽屉 | 9 | 本轮主战场；有详情端点的先改 |
