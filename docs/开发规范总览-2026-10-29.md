## 2. 不可违反的铁律（10 条，`00-core.md` §3）

1. **禁止伪造/模拟测试结果**：没跑标注"未验证"。
2. **后台 exit code 不可信**：Maven/Node 跑完 grep 日志 `BUILD SUCCESS|BUILD FAILURE|Tests run:.*Failures: [1-9]`（先 `tr -d '\000'`）。
3. **未经 robin 显式批准，绝不 `git commit`**。
4. **改契约前全量 grep 依赖者，改完再 grep 残留**。
5. **多会话并行会抢改**：宣告完成前重跑最终门禁；全量被阻塞用 `-pl` 定向并**如实标注**。
6. **断言"已写入"必须读回来核对**，不靠工具 success。
7. **回复一律简体中文**（技术术语留英文）。
8. **判定违反前先声明尺子**：SOLID 主 + DRY/KISS/YAGNI 辅 + 工程判据 E1–E5（**不属设计模式**，不得混称）。
9. **规范与代码冲突以代码为准并立即修订规范**（实例：前端曾长期写"无测试框架"实则已引 vitest）。
10. **未实测的列举不进实施清单**：任何"待迁移/待删"逐项 grep 实测，未核实标"未核实"。

## 3. 门禁命令（真跑，不许跳过）

```bash
# 后端全量
mvn -f knot-server/pom.xml test
# 后端定向（某模块被并行会话改坏时）
mvn -f knot-server/pom.xml -pl knot-dal,knot-service,knot-admin test

# 前端三道（顺序固定：test → type-check → build）
cd knot-front && npm test
cd knot-front && npx vue-tsc --noEmit
cd knot-front && npx vite build
# 前端死代码门（单独跑，勿改 tsconfig）
cd knot-front && npm run type-check:strict      # = vue-tsc --noEmit --noUnusedLocals
```

⚠ 前端 `vite build` 会 tree-shake，**死代码永远绿** → 死代码必须靠 `type-check:strict` 单跑发现。
⚠ 测试必须进 CI：`.github/workflows/ci.yml` 前端 job 须显式跑 `npm test`，否则写了等于没写。

## 4. 高频红线速记（按风险分级）

### 🔴 Blocker 级（碰了就是任务未完成）

- **分层**：只有 `knot-service`(`org.chobit.knot.svc`) 能碰 `dal.mapper`（`10` §3.1）。`knot-admin`/`knot-gateway` 不得注入/调用任何 `org.chobit.knot.dal.mapper.*`；svc 对外出自己的 record，不裸传 `dal.entity`；守门 `LayeringGuardTest`（两个 app 各一份）。
- **编排跟随使用方**（`10` §3.2）：`XxxStore` 解决"谁能碰表"（只能 svc）；编排放哪看有几个 app 用——两端共用进 svc，只有一个 app 用留那 app。判据是数字（grep 引用数），不是"类名像服务"。
- **模块红线**：`knot-plugin` 类**禁止外部模块 import（含测试）**，依赖一律 `runtime`；`knot-adapter` **禁止依赖 `knot-dal`**、禁止 import `gateway.entity`（DIP，`10` §5/`80` 反模式）。
- **权限三表 + 所有 `ks_`/`kx_` 表默认不动**（改错全站 403，`10`/`30`）。
- **计费正确性**（最易静默资损，`60` §1）：
  - 每行明细必满足 `cost = tokens × price ÷ 1e6`，`price` 恒为每百万单价；禁 `new NormalizedUsageDetail` 自拼 → 走 `AbstractBillingModeCalculator.detail()`。
  - 单位归一化唯一出口 `BillingModeEnum.normalizeUnit(code)`，禁三处各写"兜底 1K_TOKENS"。
  - 金额是 **String**（8 位小数），Jackson 禁科学计数法；前端不做 number 四则运算。
  - 折扣仅供展示，不进计费逻辑。
- **fail-hard 不静默放行**（`60` §7.1 / §8.4 / §8.11）：Redis 不可用 → 503；用量提取错配 → 抛 `IllegalStateException`；降级开关方向必须是"降级=true"（默认 false=中断）。
- **错误出口单一来源**（`10` §6）：`type/code/httpStatus/stage` 由 `GatewayErrorDescriptor.of(Throwable)` 唯一决定，三出口不许各写一棵树。
- **数字列 `<if test>` 禁写 `x != ''`**（`10` §5，2026-10-29 三连撞）：OGNL 把 `''` 当 0 → `Integer status=0` 时整段被静默丢弃；守门全库扫 `MapperBlankStringPredicateTest`。
- **枚举落库用整型码**（`60` §8.15）：显式声明禁 `ordinal()` + 测试钉裸数字 + 码只增不改 + DB `CHECK`；SQL 走 `inFlightCodes` 参数禁字面量；**迁移顺序不可颠倒**（先转数字串再 MODIFY，否则 `SUCCEEDED` 截断成 0 → 重复计费）。

### 🟡 Suggestion 级（可带债，但记入）

- 命名纪律：后缀**只能白名单**（`10` §4.1）；`svc.service` 顶层只放 `@Service`，协作者进 `service.support`；同域≥2 类加域前缀；禁泛化主干名（`System/Common/Base/Manager/Util/Helper/...`，`SystemController` 是域前缀合规例外）。
- 判断分支禁裸 code 字面量：一律 `XxxEnum.YYY.code()`，禁自造常量 Support（`10` §5）。
- 前端 `status` 为 0 合法 → 禁 `if(status)`/truthy；字符串默认用 `??` 不 `||`（展示兜底除外，`20` §4）。
- 逻辑删除 + UNIQUE(code) 表四必配：物理行 count、includeDeleted、restore 端点、引用检查（`30` §4）。
- 重命名必 grep：SpEL `@beanName`/`@Qualifier`/MyBatis namespace/XML 编译期拦不住（`10` §4.6）。

### 💭 Nit 级

- 注释与方法体不同步；未用 import/死字段/死私有方法；魔法数字未提常量；展示兜底 `|| "-"` 可统一工具。

## 6. 审查尺子（`80-code-review.md`）

- **主尺 SOLID**，**辅尺 DRY/KISS/YAGNI**，**工程判据 E1–E5（非设计模式）**：
  - E1 无假成功｜E2 无死代码/死配置｜E3 无恒等抽象｜E4 失败不静默｜E5 测试真在跑。
- 判违反必须给 `file:line`；判尺前先声明用哪条。
- 分级：🔴 Blocker（7 项 B1–B7）/ 🟡 Suggestion（8 项 S1–S8）/ 💭 Nit（4 项 N1–N4）。
- 流程：声明尺子 → 脚本初筛 → **逐个 grep 复核排误报**（铁律，脚本输出不可直接交付）→ 定档 → 记台账。

## 7. 反模式台账（最痛的几条，`80` §3 实证）

| 反模式 | 后果 |
|---|---|
| 假成功接口 / 未实现功能静默降级 | 返回 OK 但无真实计算；MASK 配了从未生效（已根除） |
| 适配层反向依赖 dal | `adapter` compile 依赖 `dal` → 7 主类穿 entity，必须下沉自有 model |
| 错误出口分叉 | 同一异常 HTTP/Kafka/日志三处 type 不一致 → 数仓记错 |
| 权威枚举未复用 | 已有枚举却手写字符串字面量（B4） |
| 兜底值 vs 权威默认值并存 | 计费单位基数四处兜底 → 1000× 静默错价 |
| `||` 误用 | `row.status \|\| "ENABLED"` 把空串当启用（已改 `??`） |
| 测试不进 CI | 10 个 spec 而 CI 只跑 type-check+build（已加 `npm test`） |

## 8. 反模式：拆分定式（`80` §6，最易踩的坑）

- 判据是**抽象层级不是行数**；跨抽象层实现细节必拆，同层子资源 CRUD 不拆。
- 抽前先照抄写测试再抽；只抽状态机/纯函数不抽编排；外部/DOM 依赖走注入。
- ⭐ **触发时机留宿主**：子组件别加 `onMounted(fetch)`，暴露 `defineExpose({refresh})`，宿主 watcher 调。
- **一次就绿的测试必打双向探针**：删守卫看是否恰好 N 例变红；探针未变红先怀疑打偏（5 种形态）。
- jsdom 两坑：点 `<label>` 不激活 radio（打 `.el-radio-button__original-radio`）；`el-select` 下拉 teleport 到 body 需 `enableAutoUnmount` + 跨用例清 mockResolvedValue。

## 9. 交付与收口（`70-delivery.md`）

- 落盘：报告 `docs/<主题>-YYYY-MM-DD.md`；迁移 `docs/database/migration/YYYY-MM-DD-<主题>.sql`；日志 `.workbuddy/memory/YYYY-MM-DD.md`（只追加）。
- 收口检查表：① grep 依赖者 ② 改完 grep 残留 ③ `mvn test`+`vue-tsc`+`vite build` ④ 涉启动装配/插件/配置 → 真启 jar 冒烟 ⑤ 临时库 DROP 零残留 ⑥ 重跑最终门禁。
- 沟通：结论先行 + 证据链（file:line）+ 表格 + 未验证项显式标注。

## 10. 本机环境陷阱（实测，`00-core.md` §4 / `50` §3）

| 陷阱 | 正确做法 |
|---|---|
| PowerShell 不回传 stdout | `\| Out-File -Encoding utf8` 落文件再读（默认 `>` 是 UTF-16） |
| Bash 缺 coreutils | 先 `export PATH="/d/Program Files/Git/usr/bin:$PATH"` |
| Bash 不传 env 给子进程 | 用 PowerShell `$env:JAVA_HOME` 直调 `mvn.cmd`，或全走命令行参数 |
| safe-delete 静默失败 | 用 `[System.IO.File]::Delete`；删完 `Test-Path` 复核 |
| Git Bash 下 mvn classpath 失效 | 路径用 `D:/...` 不用 `/d/...` |
| JDK25 + Mockito 不能 mock 具体类 | 测试替身用子类覆写，mock 接口不受影响 |
