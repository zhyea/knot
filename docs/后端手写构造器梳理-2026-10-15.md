# 后端手写构造器梳理（已裁定：保持手写，仅作历史参考）

> **⚠ 已裁定（2026-10-15）：手写构造器（含 Spring bean 构造器注入）保持手写，不 Lombok 化。** 详见 `docs/standards/rules/10-backend-java.md` §8 Lombok 应用规范。本清单仅作历史参考，不再作为待办。

> 生成时间：2026-10-15。扫描范围：`knot-server/**/*.java`（排除 record / enum / interface / target 构建产物）。


## 总览

- 手写构造器的非 record 类共 **183** 个（record 已是数据载体主流，已排除）。
- 分类一 · Spring bean 构造器注入：**112** 个 —— 候选 `@RequiredArgsConstructor`
- 分类二 · 非 Spring 纯赋值构造器：**19** 个 —— 候选 `@RequiredArgsConstructor` / `@AllArgsConstructor`
- 分类三 · 非 Spring 非纯赋值：**52** 个 —— 带逻辑 / 调 super / builder / 多构造器，需逐个评估（部分不适用 Lombok）

> Lombok 化通用约束（动手前必读）：① Spring bean 字段需加 `final` 才能被 `@RequiredArgsConstructor` 纳入，须确认字段无 `@PostConstruct`/方法内重新赋值；② 调 `super(...)` 的异常类不适用；③ builder 模式类不适用；④ 多构造器类须保留一个、用 `@RequiredArgsConstructor`/`@AllArgsConstructor` 取代纯赋值那一个。
